# 关系树 · 人际合盘

一个「以我为中心」的人际关系图谱 + 综合合盘工具。不用懂命理，软件说人话：只有生日也能用，有出生时辰更细。综合**生肖 / 纳音五行 / 生命灵数 / 西方星座 / 八字**多套体系，不押注单一算法，结果只作娱乐参考。

- 纯前端，数据只存本机（localStorage），无后端、无登录、不上传。
- 手机优先，支持添加到主屏幕（PWA）、离线使用。

## 功能

- **关系树**：以「我」为中心，把身边的人挂上来；力导向图可拖拽、双指缩放，点节点看详情。
- **合盘**：选两个人，输出综合相处分析——总评分 + 各体系要点 + 一段大白话建议（合不合 / 注意什么 / 怎么相处）。
- **有/无时辰**：节点可选填出生时辰。填了排**八字**；没填只排**六字**，时柱及相关部分标「缺时辰，未算」，绝不瞎补。
- **四套皮肤**：仙气飘飘（默认）/ 水墨留白 / 鎏金夜色 / 青绿山水。
- **记录**：按生日临近排序、搜索、按关系标签筛选、生日提醒（系统通知，需用户开启）。
- **备份**：一键导出 / 导入 JSON。

## 本地运行

```bash
npm install
npm run dev          # 开发调试；手机同 WiFi 可加 --host
npm run build        # 产物在 dist/（含 PWA 生成）
npm test             # 规则模块单元测试（37 个）
npm run icons        # 从 public/icon.svg 重新生成 PNG 图标（可选）
```

## 部署到 Netlify

根目录已配好 `netlify.toml`（build = `npm run build`，publish = `dist`，Node 20）和 `public/_redirects`（SPA 路由回退）。三种方式任选：

1. **拖拽上传（最快）**：本地 `npm run build` 后，把 `dist/` 文件夹拖到 Netlify 的 *Sites → Deploy manually*。
2. **连接 Git 仓库**：把项目推到 GitHub/GitLab，Netlify 新建站点时选择该仓库，构建命令与发布目录会自动读 `netlify.toml`。
3. **Netlify CLI**：
   ```bash
   npm i -g netlify-cli
   netlify login
   netlify deploy --prod --dir=dist
   ```

> 新站默认是**私有**（仅登录者可访问）。要公开给别人用，在站点 *Site settings → General → Access* 里切到 **Public**，或建站时选公开。

## 添加到主屏幕

- **iPhone / iPad**：用 Safari 打开 → 点底部「分享」→「添加到主屏幕」。
- **安卓**：用 Chrome 打开 → 右上角菜单 →「安装应用」或「添加到主屏幕」。
- **微信内置浏览器不支持 PWA**，请复制链接到系统浏览器打开。

## 规则依据（主流口径）

- **八字排盘**：年柱以**立春**为界；月柱以 12 个「节」为界（五虎遁）；日柱以 2000-01-01 = 戊午 为锚点推排，**23:00 起算次日**（晚子时换日）；时柱按时辰 + 五鼠遁。
- **节气**：内嵌寿星天文历（`lunar-javascript`，秒级精度），边界日出生也不会排错。
- **生肖**：以**立春**为界（与八字年柱一致），不需农历换算。
- **纳音**：六十甲子纳音（30 对）。
- **生命灵数**：保留大师数 11 / 22 / 33，不化简。
- **星座**：西方 12 星座（仅娱乐参考，弱权重）。

**简化假设**：时间按**北京时间钟表时间**处理，不引入真太阳时（可后续扩展）。

> 所有结果仅供娱乐参考，不构成任何建议。遇到流派分歧时以「说人话」和主流口径为准。
